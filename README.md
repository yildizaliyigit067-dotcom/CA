## İçerik

- `01_elementary_CA.ipynb`: Tek boyutlu hücresel otomatların sıfırdan yazılması (Kural 0, 30, 90, 110), gözlem tablosu, küçük araştırma (Kural 90 için N1(t) formülü) ve çıkış sorusu.
